# BikeMB 需求草稿

这是早期需求草稿，正式需求请以 `openspec/` 中的文档为准。

## 一句话描述

BikeMB 是一个基于 `ESP32-S3` 与圆形屏幕的自行车码表项目。第一阶段先完成基础骑行信息显示，后续再逐步扩展为更完整的骑行中控。

## MVP 目标

- 进入主界面
- 显示速度
- 显示单次里程
- 显示骑行时间
- 显示电池电量
- 支持页面切换
- 保存总里程

## MVP 暂不包含

- GPS
- 手机连接
- 轨迹记录
- 地图导航
- 心率
- OTA
- 触摸交互

## 当前实现策略

- `src/firmware/bringup`：继续保留为硬件验证工程
- `src/firmware/bikemb`：作为正式 demo 工程
- 正式 UI 使用 `LVGL`
