# BikeMB 需求草稿

## 一句话描述

BikeMB 是一个基于 ESP32 和 1.8 寸圆形屏幕的自行车码表，第一版用于显示基础骑行数据，后续逐步扩展为更智能的骑行中控。

## 用户故事

- 作为骑行者，我希望骑行时能快速看到当前速度。
- 作为骑行者，我希望知道本次骑行距离和用时。
- 作为设备制作者，我希望总里程能断电保存。
- 作为学习者，我希望项目能拆成多个小步骤，方便每次让 AI 协助实现和验证。

## MVP 必须有

- 开机进入主界面
- 当前速度显示
- 单次距离显示
- 骑行时间显示
- 电池电量显示
- 按键切换页面
- 总里程保存

## MVP 可以没有

- GPS
- 手机连接
- 轨迹记录
- 地图导航
- 心率
- OTA
- 触摸操作

## 下一步需要你确认

1. ESP32 开发板具体型号。
2. 圆屏分辨率和驱动芯片。
3. 是否带触摸。
4. 是否已有霍尔传感器。
5. 供电方式。
6. 你更想用 Arduino IDE 还是 VS Code + PlatformIO。
