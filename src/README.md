# BikeMB source assets

This directory holds development inputs that are consumed by firmware build or
generation scripts, but are not project documents.

- `assets/source/ui/`: source UI images used by LVGL asset generation.
- `assets/audio/mode-prompts/`: source audio files used by prompt asset generation.

- `src/firmware/`: PlatformIO firmware projects for bring-up and the main BikeMB demo.
