# Change: implement round UI concept

## Goal

Implement the approved three-page round display concept in `firmware/bikemb` using native LVGL widgets.

## Scope

- Home page with speed, battery, mode, time, trip distance, and assist power.
- Rate waveform page with a cyan trend graph and compact status strip.
- Detail page with ride distance, ride time, total distance, and average speed.

## Non-goals

- Real sensor integration.
- Figma or SquareLine import/export.
- New input handling for physical page switching.
