# 变更提案：初始化基础自行车码表 MVP

## 背景

用户拥有一块 ESP32 嵌入式硬件和 1.8 寸圆形屏幕，希望以 vibe-coding 的方式学习并开发一个类似现代 e-bike 中控视觉形态的自行车码表。当前阶段不开始写固件代码，先建立需求文档和项目结构。

## 目标

建立 BikeMB 项目的第一版需求和 OpenSpec 风格目录，为后续代码实现提供稳定边界。

## MVP 功能范围

- 通过轮速传感器计算速度。
- 显示当前速度、单位、单次里程、骑行时间和设备电量。
- 通过实体按键切换页面。
- 保存总里程和基础设置。
- 提供适合圆形屏幕的主界面信息结构。

## 非目标

- 不实现电机控制。
- 不实现复杂导航。
- 不实现手机 App。
- 不实现云同步。
- 不实现完整硬件驱动代码。

## 主要假设

- 第一版优先采用霍尔传感器 + 磁铁方案。
- 设备有至少一个实体按键。
- 电池电量可以通过 ADC 电压采样估算。
- 屏幕驱动和分辨率后续补充。

## 风险

- 屏幕驱动芯片未知，可能影响图形库选择。
- ESP32 具体型号未知，可能影响引脚、内存和蓝牙能力。
- 如果没有电池采样电路，电量显示只能先做占位。
- 如果屏幕刷新效率不足，需要优化 UI 刷新策略。
