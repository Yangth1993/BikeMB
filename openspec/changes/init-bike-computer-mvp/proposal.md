# 变更提案：初始化 BikeMB 基础码表 MVP

## 背景

BikeMB 需要先建立一个稳定的最小产品边界，再在此基础上推进固件实现。

当前硬件 bring-up 已完成，因此本变更除了保留初始需求定义之外，还需要把方向明确到正式 `LVGL` demo 工程。

## 目标

- 建立第一阶段 MVP 的需求边界
- 固化当前硬件与 bring-up 结论
- 明确正式工程采用 `src/firmware/bikemb + LVGL`

## MVP 范围

- 速度显示
- 单次里程
- 骑行时间
- 电量显示
- 总里程持久化
- 页面切换
- 圆屏主界面

## 非目标

- 电机控制
- 手机 App
- 云同步
- 复杂导航
- OTA

## 主要假设

- 第一版轮速方案优先使用霍尔传感器
- 板上至少会有一个可用于切页的实体输入
- 电池电量可由 ADC 电压估算
- 第一版正式 UI 使用 `LVGL`

## 风险

- 轮速传感器方案尚未最终落地
- 电量估算需要后续校准
- 圆屏 UI 在性能和布局上仍需通过正式 demo 验证
