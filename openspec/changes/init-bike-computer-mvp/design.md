# 设计草案：BikeMB MVP

## 目标

第一版设计先建立清晰的软件分层，而不是一次性实现所有业务功能。

## 系统分层

- `platform`
  - 板级初始化
  - LCD flush
  - 背光
  - 触摸和按键适配
- `app`
  - dashboard 页面
  - demo 数据源
  - 后续业务应用扩展
- `storage`
  - 设置和总里程保存

## 当前阶段页面策略

正式 demo 工程第一版先尽量复刻 bring-up dashboard：

- 标题
- `CPU`
- `FPS`
- `MEM`
- `PSRAM`
- 一个简单动效区域

这样可以先证明：

- `LVGL` 已跑通
- 正式分层结构成立
- 显示链路可支撑后续应用开发

## 后续扩展

当 `bikemb` demo 稳定后，再逐步接入：

- 真实轮速
- 电池采样
- 页面切换
- 设置页
- 数据持久化
