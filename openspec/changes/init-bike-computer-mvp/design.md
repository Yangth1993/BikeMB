# 设计草案：BikeMB MVP

## 系统模块

MVP 建议拆成以下模块：

- `sensor`: 轮速脉冲、电池电压、按键输入
- `ride`: 速度、距离、时间、状态机
- `storage`: 设置和总里程保存
- `ui`: 圆屏页面和刷新
- `config`: 引脚、轮径、单位、亮度等配置

## 状态机

第一阶段建议状态：

- `booting`: 启动中
- `idle`: 待机，未检测到骑行
- `riding`: 正在骑行
- `paused`: 暂停或静止
- `settings`: 设置界面
- `low_battery`: 低电量提示状态

## 页面

### 主界面

优先显示：

- 当前速度，大数字
- 速度单位，km/h 或 mph
- 单次里程
- 骑行时间
- 电池图标或百分比

### 数据界面

显示：

- 单次里程
- 骑行时间
- 平均速度
- 最高速度
- 总里程

### 设置界面

第一阶段只保留少量设置：

- 单位：km/h 或 mph
- 轮径/轮周长
- 屏幕亮度
- 清零本次骑行

## 数据计算

速度建议从轮速脉冲得到：

- 每次有效脉冲代表车轮转动一圈。
- 单次距离增加 `wheel_circumference_mm`。
- 当前速度可由最近两次脉冲间隔计算。
- 速度显示需要做简单平滑。
- 长时间无脉冲时速度归零。

## 存储策略

建议：

- 设置变更时立即保存。
- 总里程不要每个脉冲都保存。
- 可按固定间隔或骑行结束时保存总里程。
- 写入前判断变化量，减少 Flash 写入。
