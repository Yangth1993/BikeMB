# BikeMB 项目说明

## 项目目标

BikeMB 是一个用于学习和实践嵌入式开发的自行车码表项目，运行在带圆形屏幕的 `ESP32-S3` 开发板上。

第一阶段只实现基础骑行信息显示，不控制电机，不接入整车动力系统。

## 第一阶段定位

第一阶段目标是先做一个可上板、可扩展、可持续迭代的基础码表。

优先关注：

- 真实可运行
- 页面可读
- 数据链路可逐步替换
- 代码结构可继续扩展

## 当前技术方向

- 板卡：Waveshare `ESP32-S3-Touch-LCD-1.85C V2`
- 固件环境：`PlatformIO + Arduino`
- bring-up 工程：`src/firmware/bringup`
- 正式工程：`src/firmware/bikemb`
- UI 框架：`LVGL`

## 范围

第一阶段核心能力：

- 实时速度
- 单次里程
- 骑行时间
- 总里程保存
- 电池电量显示
- 至少一个实体按键切换页面

第一阶段暂不包含：

- 电机控制
- 手机 App
- 云同步
- 复杂导航
- OTA

## 协作方式

推荐每次开发按这个顺序进行：

1. 先更新 `openspec/changes/`
2. 明确任务边界
3. 做最小实现
4. 本地构建或上板验证
5. 回写 `docs/` 中的上下文

## 文档约定

- 新增功能先进入 `openspec/changes/`
- 确认后再合并进入 `openspec/specs/`
- `docs/` 用于沉淀当前真实状态，不替代正式规格
